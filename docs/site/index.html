The problem

Research agents sound confident.
Their numbers are often made up.

An analyst who quotes "revenue up 8%" has to be able to show where 8% came from. Stock Desk makes that a rule enforced in code: an agent may only write a number that a tool put in the ledger, and the chief checks each one before anything reaches the channel.

How it works

A desk of four agents, one Switch room.

Slack channelYou type @desk-chief analyze NKE. Teammates watch and can interrupt.
Switch roomRoutes mentions to agents, keeps the debate in one thread, stores verdicts as room documents.
desk-chiefRuns two rounds, verifies, orders a precedent check, writes the card.
Three analystsFundamental (SEC filings), technical (prices), sentiment (news). They answer only the chief.
Evidence ledgerPython tools write every fact as E1, E2 … with source, tier and link.
01

Ask the goal

desk-chief

Short term (1–4 weeks), medium (3–6 months), long (1–3 years) or all. All three horizons are always computed; the goal picks the headline.

02

Round 1: scoped reports

three analysts

Each analyst gets a scope line and runs one tool with the widest settings: 12 quarters of SEC filings, 2 years of prices, 90 days of news.

03

Verify every number

verify.py

Each report is checked line by line against the ledger. A wrong figure goes back to the analyst with the stored value; it is corrected or withdrawn, and the log keeps both.

04

Round 2 and precedent

desk-chief

One to three targeted questions, then past comparable events with opened source pages, and the stock's return against its sector after each one.

05

Verdict card

confidence.py

Outlook per horizon is the chief's judgment from verified evidence. Confidence comes only from a fixed rule. The card goes to the channel; the full evidence table is saved in the room.

Guardrails

Enforced in code, not in a prompt.

evidence/<run>/E<n>.json

No number without an ID

Tools write every fact with its value, unit, period, source, link and tier. Agents never calculate or recall a number; they cite the ID.

verify.py

Every figure checked

Reports are scanned for numbers. Each must match a cited entry within the rounding it shows; uncited numbers fail. Corrections and withdrawals are logged, never overwritten.

confidence.py

Confidence by rule

Starts at medium. One level off for missing data, fewer than 3 precedents, an uncorrected citation or news that disagrees. High only when the key analysts agree and every citation passed. Long term caps at medium.

fail closed

Missing data says so

A refused news call becomes "no data" and lowers confidence. Stale filings are dropped: the audit caught JPM revenue from 2014 being treated as current, and the tool now refuses it.

source_tier

Every source ranked

T1 for SEC filings, T2 for market data (labelled unofficial), unrated for anything else. A derived figure takes the weakest tier of its inputs.

ADVICE scan

Research, not advice

Every report and the draft card are scanned for buy, sell, price target, "good to buy" and "guaranteed". A match blocks the card until it is rewritten.

Use it

Two ways in.

Teammates use the desk by typing in Slack. Whoever hosts it sets it up once on the machine that runs the agents.

1

Start a run

Post a new message in the desk channel. Add a goal and a focus if you like.

@desk-chief analyze NKE medium, focus on debt

Spell agent names exactly. A misspelled name gets no reply. Tickers with news names ready: NKE, AAPL, MSFT, TSLA, KO, PG, DIS, HD, WMT, COST.

2

Answer the goal question

If you didn't name a goal, the chief asks. Reply in its thread, with the mention.

@desk-chief 2
3

Watch, or step in

The debate stays in the thread; the card appears in the channel in about 7 to 10 minutes. These work at any time:

@desk-chief explain E159
What fact E159 is, its source and tier, whether it passed, and who cited it
@desk-chief evidence
The full evidence table for the run, as a file
@desk-chief ask technical: …
Forwards your question to one analyst and posts the answer
@desk-chief verdict now
Skips to the verdict
@desk-chief pause / resume
Holds the run, then continues

Any other message you post during a run is treated as new evidence and routed to the right analyst.

4

Find past verdicts

Every verdict is saved in the room. List them in the channel; the next run on the same ticker quotes the last one.

!list-documents
5

Hands-free (optional)

Dictate commands into Slack with Wispr Flow or any dictation tool; add the four agent names to its dictionary. To hear replies, the host runs scripts/narrator.py, which reads each line starting with 🔊 aloud and never posts.

1

Get the code

Python 3.11 or newer. Tests run offline and must pass.

git clone https://github.com/karan-patel11/stock-desk.git && cd stock-desk
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pytest -q
2

Add your SEC contact

Copy .env.example to .env and set SEC_USER_AGENT to an app name and your real email. SEC requires it; the tools refuse the placeholder. Then check every data source once.

cp .env.example .env
scripts/smoke_live.sh NKE
3

Run Switch and connect Slack

In Switch Console, choose "Run a server on this computer", then connect Slack with Switch's Slack guide (Socket Mode). Note the connection's name.

4

Load the desk template

Templates → Import template → choose switch/desk-team.template.yaml → Save → Use template. Fill in the ticker, the absolute path of this folder, the venv Python (…/stock-desk/.venv/bin/python) and your Slack connection, then Create all.

5

Check each agent's instructions

Open each desk agent in Switch Console (Your Agents → the agent → Agent settings). If its instructions still show {python} or {stockdesk_home}, copy the filled-in text and paste it over the box, then Save. For desk-chief, from the repo folder:

python3 -c 'import sys; t = open(f"agents/{sys.argv[1]}.md").read(); print(t.replace("$STOCKDESK_HOME", sys.argv[2]).replace("$STOCKDESK_PY", sys.argv[3]), end="")' chief "$(pwd)" "$(pwd)/.venv/bin/python" | pbcopy

Repeat with fundamental, technical and sentiment. On our Switch Console (0.40.1) the template left those placeholders unfilled.

6

Let teammates talk to the desk

By default each agent answers only its owner ("Who can talk to your agent: Me and my agents"). For a team, change that setting on all four desk agents so the people in the room can reach them. Anyone who can address the agents can start tool runs on the host machine, so only do this in a channel you trust.

7

Reset and run

In the Slack channel, send each reset as its own plain message, then start a run.

!reset @desk-chief
!reset @desk-fundamental
!reset @desk-technical
!reset @desk-sentiment
8

Before a demo: warm the news cache

GDELT allows one request every 5 seconds and blocks for hours after bursts. Set STOCKDESK_CACHE_TTL_HOURS=24 in .env, then make this the first news call of the day.

scripts/warm_demo.sh NKE

Known limits

What it does not do yet.

Every limit is written down in DECISIONS.md, next to the audit that found it.

Sentiment is unweighted

One 90-day GDELT tone over every matching article. Tone weighted by source was designed and deferred: GDELT gives no per-article tone.

Banks and insurers are unsupported

Their revenue uses tags the filings tool does not read, so revenue comes back as no data.

Prices come from an unofficial client

yfinance can be rate limited or change without notice, and its latest bar can move during the evening.

Run outside US market hours

A bar from a session still trading can appear as the last close; there is no partial-bar check.
